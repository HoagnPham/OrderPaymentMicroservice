# Rà soát và chạy lại project — 13/10/2026

Đã build solution, chạy toàn bộ .NET suite và khởi động executable
`OrderPaymentMicroservice.dll` thật trong Development với PostgreSQL/journal tạm.
Chrome truy cập shop qua HTTP thật ở port động; không mock response của API trong
smoke test này. Không áp dụng migration vào database phát triển, không truy cập ATPM.

## Lỗi đã sửa trong lượt rà soát

| Vấn đề | Sửa | Kiểm chứng |
| --- | --- | --- |
| API URL cố định http://localhost:5246 gây sai origin/cổng/HTTPS | Dùng /api cùng origin của shop | Chrome flow trên port động |
| Cache user JSON hỏng làm DOMContentLoaded dừng | Parse/validate cache, bỏ cache sai và trở về chưa đăng nhập | Inject cache hỏng trước khi mở shop |
| Đọc lỗi bằng json rồi text trên cùng body đã consumed; payment chỉ nhận JSON | readApiError đọc body một lần, hỗ trợ text/JSON và giữ metadata | Browser regression text/structured errors |
| Form yêu cầu/gửi thông tin thẻ dù DTO/gateway mô phỏng không dùng | Chỉ gửi orderId/amount, bỏ input thẻ và mô tả mô phỏng chính xác | Quan sát request HTTP thật, payload chỉ hai field |
| Logout không cập nhật navbar | updateNavBar và reset form khi logout | Chrome logout trở về auth, ẩn user info |
| Hai lần bấm payment có thể phát hai HTTP requests | In-flight guard và kiểm order/amount trước tạo key | Hai handler đồng thời chỉ phát một request |
